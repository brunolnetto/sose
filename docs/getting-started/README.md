# Getting started

SOSE is easiest to learn by separating three responsibilities:

```text
domain owns meaning
core owns durable mechanics
backend owns ephemeral execution
```

Start with [Build your first durable domain](first-domain.md).

The tutorial intentionally uses one tiny entity and one scheduled transition.
After that example is clear, use the larger Reference implementations for
domain-specific patterns such as resources, Store selection, preemption,
immutable occurrences, interval ownership, and correction lineage.
